# UI 自动化测试（Playwright）

覆盖论坛主链路回归：浏览 → 搜索 → 详情 → 登录 → 发帖 → 退出。

## 环境

- Python + Playwright 1.62.0（chromium）
- 测试账号：通过 `FORUM_USER` / `FORUM_PWD` 环境变量配置（参考仓库根目录 `.env.example`）
- 未配置账号时，脚本只运行 E2E-01~03 只读场景，E2E-04~06 记为跳过
- 脚本默认只允许本地实例；远程环境需设置 `FORUM_ALLOW_REMOTE_TESTS=1`（仅限已获授权环境）

## 运行方式

```bash
cd 06_UI自动化
# 先按需设置 FORUM_BASE / FORUM_USER / FORUM_PWD / FORUM_DISCUSSION_ID / FORUM_SEARCH_KEYWORD / FORUM_TAG_NAME
python run_ui_e2e.py
```

依赖：`playwright`（本项目 1.62.0 + chromium）。首次使用需 `playwright install chromium`。

## 关键技术点

- **选板块**：Flarum 板块选择器为 `a.DiscussionComposer-changeTags`（"选择标签"），弹窗内标签列表为 `.SelectTagList li`，选中主标签后需点"确定"提交。
- **用户下拉菜单**：Flarum 下拉菜单 DOM 常驻（隐藏状态），靠 `.open` class 显示。退出按钮 `.item-logOut button` 即使隐藏也可用 `click(force=True)` 触发（事件已绑定）。
- **发帖控频**：受 BUG-003（发帖限流阈值过严，第2帖即429）影响，脚本每轮只发 1 篇，避免触发限流。
- **网络抖动**：`goto_retry` 包装重试 3 次，规避该站点偶发加载超时。

## 测试数据清理

E2E-05 会真实发布一篇标题含 `【UI自动化】` 的帖子。运行后按标题前缀回收（Flarum 软删除）：

```bash
python cleanup_ui_test.py            # 试运行：只列出待清理帖子，不删除
python cleanup_ui_test.py --apply    # 确认后实际执行软删除
```

脚本只处理**作者为测试账号、且标题带 `【UI自动化】` 或 `【测试】` 前缀**的帖子，不会触碰他人内容；
开头带鉴权自检，未登录成功会直接终止而不是误报「无内容可删」。

**已隐藏的帖子会被识别并跳过**：作者视角的帖子列表**包含自己已隐藏的内容**，不区分的话，
早前清理过的帖子会被反复报成「待清理」，把「还有 N 条没回收」说大（与
`03_接口测试/接口自动化/cleanup_api_test.py` 口径一致）。试运行输出会分别给出
「待清理」与「已隐藏」两个数，`--apply` 时对已隐藏项直接跳过、不重复发请求。

执行记录运行后写入本目录 `清理结果.json`（命中项 / 已隐藏项 / 是否实际执行；运行时产物，已在 `.gitignore` 中）。
