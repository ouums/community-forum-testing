# 缺陷摘要

原项目共确认 **3 条**缺陷：P1 严重 2 条、P2 一般 1 条。以下只保留编号、模块、现象、
影响与回归方式；完整复现步骤、截图、原始请求 / 响应记录留在私有目录，不在公开仓库分发。

> 说明：项目对 3 处疑似缺陷做过复核并全部排除（脚本取文本过早、UI 按钮与 API 权限两套判据、
> 搜索命中正文但标题不含关键词），未写入缺陷报告。详见 `05_测试报告/测试报告摘要.md`。

## BUG-001 中文搜索失效

| 项 | 内容 |
|---|---|
| 等级 | P1 严重 |
| 模块 | 搜索 |
| 关联用例 | TC-030；接口回归 `test_search_chinese`、`test_search_chinese2` |
| 现象 | 使用中文关键词（如“接口”“测试”）搜索返回 0 条；数字 / 英文关键词可正常命中 |
| 预期 | 标题或正文包含关键词的帖子应出现在结果中 |
| 影响 | 中文检索基本不可用，直接影响论坛核心查找体验 |
| 状态 | 报告出具时未修复；接口套件以 `xfail(strict=True)` 固化回归 |
| 备注 | API 层复核确认搜索接口对中文关键词返回空列表，排除“页面渲染问题” |

## BUG-002 登录接口缺少失败限流

| 项 | 内容 |
|---|---|
| 等级 | P1 严重 |
| 模块 | 接口测试-权限与限流 |
| 关联用例 | TC-044；接口回归 `test_login_rate_limit_missing` |
| 现象 | 对同一测试账号连续 10 次使用错误口令，全部返回 401，未出现 429，也未触发账号锁定 |
| 预期 | 连续失败达到阈值后应触发限流（429）或失败锁定 |
| 影响 | 登录失败尝试可被反复枚举，缺少常规防爆破保护 |
| 状态 | 报告出具时未修复；接口套件以 `xfail(strict=True)` 固化回归 |
| 备注 | 样本量为 10 次错误口令；若系统阈值高于此，本条不足以证明“完全无限流”，但足以证明“未见常规防爆破响应”。对照发帖接口第 2 帖即 429，说明限流中间件存在但未覆盖登录接口 |

## BUG-003 发帖限流阈值过严

| 项 | 内容 |
|---|---|
| 等级 | P2 一般 |
| 模块 | 接口测试-权限与限流 |
| 关联用例 | TC-045；接口回归 `test_rate_limit_too_strict` |
| 现象 | 第 1 帖发布成功后，紧接着发布第 2 帖即返回 429 |
| 预期 | 限流应允许一定频率的正常发帖，只对高频滥用拦截 |
| 影响 | 正常用户连续发帖被阻断；连带阻断 3 条写接口自动化用例、1 条功能用例（TC-049）与写接口性能测试 |
| 状态 | 报告出具时未修复；接口套件以 `xfail(strict=True)` 固化回归 |
| 备注 | 关联用例 TC-045 执行结果为“通过”（限流确实生效），“阈值过严”单独记为本缺陷 —— 用例通过不等于功能无缺陷 |
